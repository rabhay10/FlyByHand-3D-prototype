# \# Hand Gesture Controlled Drone (Simulation)

# 

# This project uses \*\*computer vision and hand gestures\*\* to control a drone.

# Currently runs in \*\*simulation mode\*\* using OpenCV.

# 

# \## Gestures

# \- ✊ FIST → Takeoff

# \- ✋ Open Hand → Land

# \- ☝️ Index Up → Move Forward

# \- ✌️ Index + Middle → Move Backward

# \- 👍 / 👎 Thumb → Rotate Left / Right

# 

# \## Tech Stack

# \- Python

# \- OpenCV

# \- MediaPipe

# \- NumPy

#
